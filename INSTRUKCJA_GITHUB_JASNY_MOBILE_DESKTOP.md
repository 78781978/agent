# Vie AI — jasny motyw na komputerze i telefonie

Paczka `github-w1-w4-jasny-mobile-desktop.zip` zawiera komplet W1–W4, logo, tło, favicon, poprawione proxy oraz pełną korektę czytelności jasnego motywu.

## Wgranie

Rozpakuj ZIP w głównym katalogu repozytorium, zachowaj strukturę folderów i zaakceptuj podmianę. Następnie wykonaj commit i redeploy.

Główna zmiana:

- `app/globals.css` → `/app/globals.css`

Poprawiono kontrast nagłówków, opisów, kart, formularzy, tabel, nawigacji i wiadomości oraz układ nawigacji na ekranach do 640 px.
